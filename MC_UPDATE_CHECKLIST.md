# Minecraft version update checklist

If there is a new Minecraft version, ensure the steps below are completed. Order matters!  Updating paper is explicity left out, as we follow a version skew policy that keeps the lobby servers on the previous version for a certain amount
of time.

- [ ] Update resource pack
- [ ] Update ViaVersion 
  - [ ] Lobby proxy
  - [ ] Gateway
- [ ] Update Velocity
  - [ ] Lobby proxy
  - [ ] Gateway
