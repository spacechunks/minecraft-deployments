# Documentation Overview

This repository uses namespaces to organize models, textures, and shaders across multiple Space Chunks projects.

## Namespaces

Each namespace separates content into logical groups to prevent naming conflicts.

Namespaces are defined in two locations:
- Files: `pack/assets/`
- Configurations: `items/`

### Registry

| Namespace | Category | Purpose |
| :--- | :--- | :--- |
| `minecraft` | Vanilla | Overwrites for vanilla assets. |
| `spacechunks-extended` | Global | Shared custom blocks and decorative models. |
| `chunkexplorer` | Project | Exclusive assets for Chunk Explorer projects. |
| `starleague` | Project | Exclusive assets for Star League projects. |
