Minecraft blueprints
====================

This repository contains all blueprints for our Minecraft deployments.

Note the following:
* Environment variables that need to be set:
  * `BUILD_OCI_REG_USER`: Registry user
  * `BUILD_OCI_REG_PASS`: Password for registry user
  * `BUILD_OCI_REG_SERVER`: Registry endpoint e.g. ghcr.io
